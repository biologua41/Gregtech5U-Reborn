# Gregtech5U-Reborn
GT5U Reborn — наша собственная сборка Minecraft 1.7.10 на базе GregTech 5 Unofficial. Сложные рецепты, технологии, автоматизация, новые производственные цепочки и собственные механики. Мы развиваем проект, тестируем баланс и добавляем новый контент, сохраняя дух старого Minecraft 1.7.10.
